# Changelog

Версия единая для Android-приложения и HA-интеграции.

## v0.7.8
- Настройка mute — чекбокс «Заглушать звук при старте окна».
- Синхронизация в обе стороны: иконка динамика в окне и mute-параметр
  команды из HA пишут ту же настройку, что и чекбокс.
- Интеграция: настройка «Заглушать звук при показе окна» в.options
  устройства; у службы mynotify.show новый параметр mute (true/false).

## v0.7.7
- Ручки ресайза — маленькие треугольнички в левом нижнем и правом верхнем
  углах окна (вместо серого квадрата), тянутся за оба угла.
- Android TV: пульт переключает кнопки панели окна (стрелки — навигация по
  кнопкам при видимой панели, ОК — нажатие; без панели стрелки двигают окно,
  +/- масштаб). Фокусированная кнопка подсвечивается синим.
- Звук по умолчанию выключен («Mute при старте окна» включён по умолчанию).

## v0.7.6
- Звук с камеры: окно воспроизводит аудиодорожку потока (все камеры
  go2rtc отдают аудио). В панели окна — иконка динамика вкл/выкл звука.
- Настройка «Mute при старте окна»: окно может открываться без звука,
  включается той же иконкой.

## v0.7.5
- Синхронизация состояния: приложение сообщает фактическое состояние
  окна в каждом опросе — закрыл окно на устройстве (X, автоскрытие) →
  `switch.mynotify_<ID>` гаснет в HA, и наоборот.
- Автостарт службы после перезагрузки телефона/планшета/ТВ (BOOT_COMPLETED;
  на MIUI дополнительно разреши автостарт MyNotify в «Безопасности»).

## v0.7.4
- Иконка приложения видна у самого APK-файла (добавлены PNG-иконки
  конфигурации по умолчанию, а не только adaptive XML).
- Сущность окна переименована: `switch.mynotify_<ID устройства>`
  (без суффикса `_push`).

## v0.7.3
- Исправлен чёрный экран «ERROR_CODE_PARSING_CONTAINER_UNSUPPORTED»:
  прокси отдавал манифест с Content-Type «…mpegurl; charset=utf-8», и
  ExoPlayer не распознавал HLS. Прокси отдаёт MIME без charset, а
  плеер для прокси-ссылок задаёт тип потока явно.
- Исправлено: при актуальной версии кнопка «Скачать и установить»
  больше не предлагается — диалог только при наличии новой версии.

## v0.7.2
- Приложение: внизу экрана — секция «Приложение» с версией и кнопкой
  «Проверить обновления»: приложение само находит последний релиз на
  GitHub, скачивает APK с прогрессом и открывает установщик.
- Интеграция: приложение сообщает свою версию при регистрации — она
  попадает в лог Core (удобно диагностировать, что реально установлено).

## v0.7.1
- Интеграция: видеопоток проксируется через HA (`/api/mynotify/stream`) —
  устройство вне домашней сети получает камеру по тому же каналу, что и
  API. Публиковать go2rtc наружу не нужно; доступ — по паре device+code,
  проксируются только ссылки локального go2rtc (защита от SSRF).
- Приложение: адрес потока строится от активного адреса HA (локальный или
  внешний); при переключении сети открытое окно переподключает поток.
- Интеграция: убрана кнопка «На весь экран» (в окне она и так есть).

## v0.7.0
- Приложение: второе поле адреса — внешний адрес HA (необязательно).
  Вне домашней сети служба автоматически переключается на него, дома
  использует локальный.
- Приложение: звук при показе окна — выбор из системных рингтонов
  (включая «Без звука»).
- Окно: кнопки панели — иконки (закрыть / во весь экран), масштаб
  подстраивается под размер окна; убраны кнопки «Скриншот» и «Запись».
- Интеграция: удалены сущности «Скриншот» и «Запись видео»
  (остались выключатель окна, список камер, кнопка «На весь экран»).

## v0.6.9
- Фирменная иконка: адаптивный значок приложения (все плотности + monochrome
  для Android 13+) и brand-ассеты интеграции (brand/icon, logo) — HA 2026.3+
  показывает её на карточке интеграции через brands-proxy.

## v0.6.8
- Приложение: редизайн интерфейса в стиле iOS — системный сгруппированный
  фон, белые карточки, крупные заголовки, акцентные цвета системы
  (сине/зелёные/красные кнопки), ночная палитра полностью поддержана;
  панель окна — iOS-капсулы на полупрозрачном фоне.
- Интеграция: entity_id выключателя показа окна —
  switch.mynotify_<устройство>_push (вместо ..._pokaz_okna).

## v0.6.7
- Очередь команд окну: хранится только последний показ/скрытие, всё
  накопившееся за сон планшета больше не «доедается» по очереди — окно
  больше не показывает старую камеру после выбора новой;
- просроченные (старше 2 минут) show/hide не выдаются вовсе;
- устранена гонка при загрузке платформ: несколько копий контроллера
  устройства приводили к расхождению списка «Камера» и реального показа.

## v0.6.6
- mynotify.show с конкретной камерой теперь синхронизирует выпадающий
  список «Камера» в UI: что показали, то и выбрано.

## v0.6.5
- Фикс запуска на HA 2026.11: убран импорт DeviceEntryType (удалён из ядра).

## v0.6.4
- Интеграция переработана: вместо одной сущности-«увлажнителя» нормальный
  набор на устройстве — выключатель «Показ окна», выпадающий список
  «Камера» (потоки go2rtc), кнопки «Скриншот», «На весь экран»,
  «Запись видео». Шестерёнка «Настройки» (reconfigure) — смена адреса go2rtc.
- Приложение 0.6.4: принимает удалённые команды screenshot/fullscreen/record.

## v0.6.3

  обязаны иметь атрибут name — добавлен. Чистка протухших заявок на привязку.

## v0.6.2
- Фикс привязки: HTTP-эндпоинты приложения регистрируются уже при открытии
  окна настройки интеграции (раньше появлялись только после создания записи —
  код не мог зарегистрироваться, «код не найден»).

## v0.6.1
- Интеграция: понятная ошибка для старых записей конфигурации (до v0.6)

- Единая версия приложения и интеграции, блок версий в README.

## v0.6
- Привязка устройства кодом из приложения: интеграция сама принимает
  подключения по HTTP (register + poll). ADB и androidtv_remote больше не нужны.
- Кнопки приложения разделены: запуск/остановка службы (фоновая, доступна
  HA в любой момент) и показать/скрыть окно (не трогает службу).
- Скрытое окно не останавливает службу (START_STICKY).
- Кнопки панели окна масштабируются вместе с размером окна.
- Одна сущность «Камера поверх экрана» на устройство: тумблер + выбор
  камеры go2rtc в more-info. Сервисы mynotify.show/hide целятся в сущности.

## v0.5
- Фоновая служба: запуск/остановка отдельно от окна.
- Масштабирование UI-кнопок окна.
